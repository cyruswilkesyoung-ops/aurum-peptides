AURUM REDESIGN — two steps, in this order

You are doing ONE upload at the end. Get the images in place first, then upload
everything together, so the site is never pointing at pictures that are not there.

STEP 1: THE IMAGES
Open 1-DOWNLOAD-THE-IMAGES.html by double clicking it. It opens in your browser
and shows all ten pictures. Right click each one, Save Image As, into the folder
named under it. Do not rename anything.

You will need to create one new folder: assets/packshots/photo/

Nine images go in assets/packshots/photo/
One image goes in assets/hero/

STEP 2: THE CODE
The 2-code folder holds 40 changed files. Copy its contents into your
aurum-peptides folder, replacing what is there.

THEN UPLOAD
github.com/cyruswilkesyoung-ops/aurum-peptides/upload/main
Drag the whole aurum-peptides folder into that page, type a message, commit.

Or hand the lot to Sirus, it is ten minutes for him.

IF AN IMAGE DOES NOT MAKE IT
Nothing breaks. Every product image falls back to the original drawing if the
photograph is missing. I tested it with all ten absent: zero broken images
anywhere on the site. So a half-finished upload looks like the old site, not a
broken one.

WHAT CHANGED
- Homepage banner is now a photograph instead of an empty space
- All 19 products use real studio photography instead of drawings
- Product cards are lit, bigger vials, gold pool, proper shadow
- Social previews and the cart drawer use the photographs too

WHAT IS NOT DONE
Nothing about payments, orders or the age gate has changed. This is only the
look of the site.
